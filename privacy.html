1. 이 도구가 하는 일

"판책임 업로더"(이하 도구)는 채널 운영자가 직접 제작한 영상을 운영자 본인의 TikTok, YouTube, Instagram 계정에 업로드합니다. 운영자 외의 사용자는 없습니다.

2. 처리하는 정보

  • 각 플랫폼이 로그인 후 발급하는 접근 토큰(운영자 본인 계정 것)
  • 업로드에 필요한 계정 식별자와 공개 프로필 이름
  • 업로드하는 영상 파일, 제목, 설명

그 밖의 개인정보(연락처, 위치, 시청 기록, 다른 사용자의 정보 등)는 수집하지 않습니다.

3. 보관과 보호

토큰은 운영자의 개인 컴퓨터에만 파일로 저장되며 외부 서버로 보내지 않습니다. 업로드 외의 목적으로 쓰지 않고, 제3자에게 제공하거나 판매하지 않습니다.

4. 삭제

운영자는 언제든 각 플랫폼의 연결된 앱 설정에서 이 도구의 권한을 해제할 수 있으며, 해제하면 저장된 토큰은 더 이상 쓸 수 없게 되고 운영자의 컴퓨터에서 삭제됩니다.

5. 문의

문의는 YouTube 채널 @panchaegim 의 정보 페이지를 통해 받습니다.

6. YouTube API 서비스 이용

이 도구는 영상을 운영자의 YouTube 채널에 올리기 위해 YouTube API 서비스를 사용합니다. 이 도구를 사용하면 YouTube 서비스 약관에 동의하는 것이며, YouTube 관련 정보는 Google 개인정보처리방침에 따라 처리됩니다.

YouTube에서 받는 정보는 업로드 권한(youtube.upload) 토큰뿐이며, 채널의 다른 데이터는 읽거나 저장하지 않습니다. 토큰은 운영자의 컴퓨터에만 저장됩니다.

권한 해제: Google 계정 보안 설정의 연결된 앱 페이지에서 언제든 이 도구의 접근 권한을 해제할 수 있습니다. 해제하거나 운영자가 요청하면 저장된 토큰은 7일 안에 운영자의 컴퓨터에서 삭제됩니다.

7. 쿠키와 추적

이 웹사이트와 도구는 쿠키, 광고 식별자, 분석 도구를 사용하지 않습니다.
